# 发版与审核清单

## 通用
- [ ] 版本号：manifest `versionName/versionCode` 已递增，更新日志已写
- [ ] 环境：`VITE_API_BASE` 指向生产，关闭 console/调试开关，移除测试账号入口
- [ ] 全平台冒烟：登录、支付、分享、退出、弱网、未授权场景

## 微信小程序
- [ ] 服务类目与实际功能一致（教育、社交、电商等需资质）
- [ ] 用户隐私保护指引已填写，涉及的隐私接口全部声明
- [ ] request/upload/download 合法域名均为 https 且已配置
- [ ] 主包 ≤ 2MB，代码依赖分析无冗余
- [ ] 审核需要登录时提供测试账号；不得强制授权才能浏览
- [ ] 无诱导分享/关注、无虚假宣传；UGC 内容接入内容安全检测（msgSecCheck/mediaCheckAsync）
- [ ] 常见驳回：功能不完整/页面空白、类目不符、未经同意收集信息、iOS 虚拟支付

## App（安卓商店 / App Store）
- [ ] 首次启动弹隐私政策，同意前不调用任何 SDK、不读取设备信息
- [ ] 权限按需申请，并有用途说明；隐私政策列出第三方 SDK 清单
- [ ] 软著（国内大多商店需要）、ICP/App 备案
- [ ] iOS：ATT 弹窗（如使用 IDFA）、隐私清单 PrivacyInfo、内购规则
- [ ] 签名证书妥善备份，不要提交到 git
